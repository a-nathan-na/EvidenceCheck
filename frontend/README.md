# EvidenceCheck — frontend

React + TypeScript + Vite web app for the EvidenceCheck API.

```bash
npm install
npm run dev      # http://localhost:5173
```

Set `VITE_API_URL` to point at the API (see `.env.example`). Setup, architecture, and
limitations are documented in the [root README](../README.md).

Scripts: `dev`, `build`, `preview`, `lint`, `format`, `format:check`, `typecheck`, `test`.
